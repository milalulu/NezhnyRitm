# Аудит и план 2.0

Исходная точка: cb25a4c, чистая ветка main. Прочитаны модели, сервисы, все SwiftUI-экраны, тесты, XcodeGen, упаковка IPA и CI. Сохраняем bundle ID, путь Application Support/NezhnyRitm/journal.json, все поля 1.0, исходную программу и снимки тренировок. Риски: синтезированный Codable не допускает добавления обязательных полей без миграции; приватный дневник нельзя целиком передавать виджету; бесплатная переподпись не гарантирует HealthKit/App Groups.

Этапы отдельных коммитов:
1. Версия JSON 2: совместимое чтение 1, защитная копия до миграции, новые опциональные поля и отдельный блок wellness; проверки миграции и операций.
2. Привычки и уход: расписания, календарь, перенос конкретного выполнения, архив, напоминания; сон, настроение, любимые блюда; комната анимированного котика и идемпотентные сердечки.
3. Тренер: иллюстрации Canvas, шаги техники, облегчённые варианты, личная настройка текущей сессии; графики по периоду и отчёты за день/неделю.
4. LocalAuthentication, скрытие при сворачивании, нейтральные уведомления, нейтральное имя «Ритм». Виджеты — отдельное расширение с минимальным снимком в App Group; не экспортировать текст, фото, сон и питание в виджет.
5. Три IPA: базовая, HealthKit, Full (HealthKit + WidgetKit/App Groups), миграционные и UI-тесты на XR, проверка бинарников, инструкция установки/обновления.

Данные: существующий JournalStore остаётся источником истины. WellnessData хранит процедуры/привычки, переносы, кошелёк и покупки питомца, избранные блюда. DayDetails содержит выполнение привычек, сон, настроение. Новые поля в старых типах опциональные. Блокировка — настройка конкретного устройства, не включается импортом чужой копии. Виджет получает только согласованный снимок сегодняшнего плана/привычек/питомца с режимом скрытия.
