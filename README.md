# Мой нежный ритм · 2.0

Нативное iOS-приложение на SwiftUI, Swift 5.9+, iOS 16+, MVVM. Русский интерфейс, iPhone XR, светлая и тёмная темы. Локальный Codable JSON, без Swift-пакетов, регистрации, аналитики, калорий, контроля веса и обязательных нормативов.

## Получить и установить IPA

Откройте успешный запуск [Build iPhone IPA](https://github.com/milalulu/NezhnyRitm/actions/workflows/build-ipa.yml), скачайте **NezhnyRitm-SideStore**, распакуйте ZIP и импортируйте `NezhnyRitm.ipa` в SideStore. На домашнем экране приложение называется **«Ритм»**. [Пошаговая установка и capabilities](docs/INSTALL.md).

| Артефакт | Возможности |
| --- | --- |
| NezhnyRitm-SideStore | Все локальные дневники, тренер, питомец, Face ID/код-пароль; ручной ввод шагов и сна. Без специальных entitlements и расширений |
| NezhnyRitm-HealthKit | Всё базовое + чтение шагов и сна из Apple Health; подпись должна разрешать HealthKit |
| NezhnyRitm-Full | Всё перечисленное + три WidgetKit-виджета; требуется согласованная подпись приложения/расширения и App Group |

GitHub может требовать вход для скачивания. IPA хранится 90 дней; workflow можно запустить снова. Сборка для iPhone не требует сертификатов; установка требует переподписи. Физическую установку с конкретной учётной записью SideStore необходимо проверить на самом iPhone.

## Что работает

- Исходная недельная программа без отжиманий, каждый подход, перенос, история и редактирование расписания. Интерактивный тренер со схемами положений, техникой, мягким темпом, настройкой подходов/повторений конкретного занятия и таймером.
- Календари привычек и ухода: свои названия, значки, дни недели, заметки, завершение, перенос отдельного события, архив и необязательные напоминания.
- Питание: фотографии, свои приёмы пищи, любимые блюда, сытость и самочувствие без оценок еды. Избранное создаёт редактируемую новую запись.
- Сон: ручная продолжительность, ощущение отдыха, заметки; при разрешении HealthKit — пересечение и объединение интервалов сна без двойного счёта. Ручная запись имеет приоритет.
- Анимированная Плюша: имя, сердечки за отметки привычек и завершённые тренировки, постоянные покупки, украшения и цвета комнаты. Повторное нажатие не даёт новую награду, пропуски не отнимают покупки и сердечки.
- Графики подходов, шагов, сна и настроения за 7/30/90 дней. Пропуски данных не превращаются в нули или выдуманные оценки.
- Отчёты для Астраси за день/неделю: предпросмотр и редактирование, копирование, системное «Поделиться», открытие ChatGPT. Отправка остаётся явным действием пользователя.
- Защита Face ID или код-паролем iPhone, нейтральное название и уведомления, прикрытие экрана в переключателе приложений, включая открытые формы.
- Виджеты Full: планы, привычки и котик; включаются отдельно. При защите входа данные скрыты. iOS управляет временем обновления виджета.

Новые экраны находятся во вкладке **«Мой ритм»**, привычки, сон и питомец также доступны с главной страницы. Основные функции работают офлайн; фотографию, хранящуюся только в iCloud, сначала нужно загрузить.

## Данные и обновление с 1.0

Идентификатор `app.nezhnyritm.NezhnyRitm` и путь `Application Support/NezhnyRitm/journal.json` сохранены. Версия схемы 2 добавляет необязательные поля. При первом чтении v1 исходный файл сохраняется как `v1-before-upgrade.json`, затем выполняется миграция. При импорте сначала проверяется весь файл и создаётся `before-import-….json`. Настройка блокировки хранится только на устройстве, импорт её не отключает.

Экспортируйте JSON перед обновлением. Устанавливайте поверх прежнего приложения, с той же учётной записью/идентификатором. Не удаляйте приложение для обновления: это удалит локальные данные. Копия содержит фото и личные записи; лимит 100 МБ, фото уменьшается до 1200 пикселей. Системная резервная копия iPhone может включать дневник.

## Сборка и проверки

```sh
brew install xcodegen
xcodegen generate
bash scripts/package_ipa.sh Release NezhnyRitm
bash scripts/package_ipa.sh HealthRelease NezhnyRitm-HealthKit
xcodegen generate --spec project-full.yml
bash scripts/package_ipa.sh FullRelease NezhnyRitm-Full
# Вернуть проект без расширения для обычных тестов:
xcodegen generate --spec project.yml
open NezhnyRitm.xcodeproj
```

GitHub Actions собирает три ARM64 IPA, проверяет упаковку и выполняет unit/UI-тесты на доступном iPhone Simulator (приоритет XR). `Test-results` содержит xcresult и снимки экранов. Тесты проверяют миграцию v1 с фото/ID, восстановление JSON, защиту повреждённых данных, сохранение истории, переносы, покупки, объединение сна и пользовательские сценарии. Результат конкретного запуска смотрите в Actions.

`App/Models` — схема и программа; `ViewModels` — операции дневника; `Services` — файлы, Apple Health, уведомления, приватность; `Views` — SwiftUI; `Shared` — палитра, рисунок котика, минимальная сводка виджета; `Widgets` — расширение. [Аудит и план миграции](docs/V2-AUDIT.md).

Напоминания: ближайшие 59 событий в пределах 56 дней + до 3 напоминаний о еде + таймер; расписание обновляется при открытии/редактировании. HealthKit синхронизируется при открытии, выборе даты/периода и изменениях во время работы приложения; фоновая доставка не заявляется. На iOS 16 нажатие виджета открывает приложение, отметки выполняются внутри.
