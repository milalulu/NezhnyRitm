# Мой нежный ритм

Нативный дневник движения, питания и самочувствия: SwiftUI, Swift 5.9+, iOS 16+, MVVM. Данные — Codable JSON в Application Support, атомарная запись, фото внутри копии. Нет регистрации, аналитики, калорий, веса или обязательных нормативов.

## Получить IPA

В [Actions → Build iPhone IPA](https://github.com/milalulu/NezhnyRitm/actions/workflows/build-ipa.yml) откройте успешный запуск и скачайте **NezhnyRitm-SideStore**. Распакуйте ZIP: внутри `NezhnyRitm.ipa`. Это настоящая ARM64-сборка для устройства, которую подписывает SideStore. GitHub может требовать вход для скачивания artifacts. Срок хранения — 90 дней; после этого запустите workflow снова.

[Установка через SideStore и ограничения HealthKit](docs/INSTALL.md).

## Возможности

- Русский интерфейс, молочно-розовые и лавандовые карточки, светлая/тёмная тема, Dynamic Type, VoiceOver; нижняя навигация и прокрутка на небольших экранах.
- Недельная программа с воскресенья, отметки подходов, техника, необязательная резинка, таймер отдыха с восстановлением после сворачивания.
- Редактирование расписания и своих упражнений, перенос на свободные дни, неизменяемые снимки прошлых занятий, календарь, история и графики. Нагрузка меняется только вручную.
- Дневник питания с собственными названиями, текстом и фотографией, редактирование/удаление, выбор дня, энергия и самочувствие.
- Ручные шаги и график за семь дней; вариант HealthKit читает шаги при открытии и изменениях HealthKit во время работы приложения. Фоновая доставка не заявляется.
- Отчёт для Астраси с редактированием текста, копированием, системным Share Sheet и переходом в ChatGPT. Отправка только пользователем. Фото в текстовый отчёт не включены.
- Локальные напоминания, JSON-экспорт/импорт с фото и проверкой версии/содержимого; перед импортом сохраняется предыдущий файл.

## Локальная сборка на Mac

```sh
brew install xcodegen
xcodegen generate
open NezhnyRitm.xcodeproj
# Не требует сертификата для упаковки:
bash scripts/package_ipa.sh Release NezhnyRitm
# HealthKit (требует подходящей подписи для установки):
bash scripts/package_ipa.sh HealthRelease NezhnyRitm-HealthKit
```

Выберите установленный Xcode с SDK iOS 16 или новее. В Xcode для запуска на физическом устройстве укажите свою команду подписи. Для тестов выберите любой доступный iPhone Simulator и выполните Product → Test. В CI выбирается доступный iPhone автоматически; результаты и скриншоты сохраняются в `Test-results`.

## Структура

`App/Models` — Codable-модели и программа; `ViewModels/JournalStore` — состояние, история и отчёты; `Services` — хранение, HealthKit, уведомления; `Views` — SwiftUI; `Tests` — проверки модели/хранения; `UITests` — сквозной сценарий питания, шагов и отчёта. Внешних Swift-пакетов нет.

## Границы версии 1.0

Виджет не включён: основное приложение обходится без App Groups и дополнительных App IDs при бесплатной подписи. Для фото из iCloud может понадобиться предварительная загрузка; уже добавленные фото доступны офлайн. Напоминания о тренировках планируются на 56 дней вперёд и обновляются при открытии приложения; питание — повторяющиеся ежедневные уведомления. JSON-копия ограничена 100 МБ, каждое фото уменьшается до 1200 пикселей. Пользовательские копии содержат личные данные — храните их там, где вам удобно и безопасно.

Тесты симулятора и проверка структуры IPA не заменяют запуск на вашем iPhone с вашей подписью SideStore. Проверка конкретной установки должна быть выполнена на устройстве.
